ぷにっと脱出
（Slime Exit）

〜異変を食べて大きくなれ！〜

ぷにぷにスライムが、一見同じ迷路の部屋を進み「前と違う違和感（異変）」を見破りながら成長して脱出する、 約1分の異変観察＆育成パズル。トーンはかわいい7割／ほの怖3割。

Platform Web / GitHub Pages Tone Cute 70% / Soft-horror 30% Goal 作品完成優先 Loop 1ステージ ≈ 1分
コア体験（一言）: 「5秒観察 → 即判定 → ぷにっと成長」の高速ループに、異変発見のアハ体験と変異図鑑の未回収欲を重ねる。

1. コンセプトと成功条件

1.1 プレイヤーに渡す感情

瞬間感情設計での作り方
入室少しの緊張「前と同じ？違う？」を想起させる間
異変発見アハ！差分が「言い当てたくなる」粒度
正解かわいさのご褒美0.6〜0.9秒の成長演出＋SE
失敗惜しい→もう1回0.8秒以内リスタート＋異変チラ見せ
クリア達成＋次が気になる新エリア／図鑑スタンプ

1.2 完成定義（v1）

項目必須後回し可
エリアダンジョン1本（7部屋）お菓子・宇宙
異変12種（逃げ／捕食）音系の本格実装
成長Lv1→7サイズ変化SSR分岐フォーム
図鑑見つけた異変の記録完全コンプ報酬
配信GitHub PagesでHTTPS再生PWA高度最適化
収益なし（作品完成優先）広告・DLC

1.3 トーン指針（かわいい7 / ほの怖3）

かわいい（7）

  • 丸み・パステル・ぷにっと弾む
  • 失敗も「ぷしゅ〜」で愛嬌
  • 異変はクスッと系を多め

ほの怖（3）

  • 影の遅れ、時計の視線
  • 青白い炎、逆再生の水音
  • 怖さは「説明しない余白」で出す
ジャンプスケア（突然の大きな音・フラッシュ）は禁止。ほの怖は「気づいたときのゾワッ」に限定する。

2. 技術選定（美しく滑らかに）

GitHub Pages・iPhone SE3・個人完結制作を前提に、仕上がりの美しさと実装速度のバランスで選定する。

候補美しさ滑らかさPages適合判定
PixiJS v8 + Vite◎ スプライト／フィルタ◎ GPU描画○ 静的出力採用
純Canvas 2D○ 手描き次第○ 軽量◎ 超単純縦スライス予備
Phaser 3○○○過剰機能が多い
Unity WebGL◎△ 初期読込重い△ 容量大不採用

2.1 採用スタック

層技術役割
描画PixiJS v8部屋・スライム・パーティクル・イージング
ビルドVite高速開発、`dist/` を Pages へ
状態明示的FSMtitle / play / result と部屋フェーズ管理
音声Web Audio初回タップでアンロック、短いSE優先
永続化localStorage図鑑進捗のみ（軽量）
ターゲットiPhone SE3 Safari375×667、タッチ、音量サイレント対策
FSM（有限状態機械）: 状態を「今なに中か」で厳密に分け、入力と描画が暴走しないようにする設計パターン。 本ゲームでは ready → observe → decide → resolve → grow/fail を部屋単位で回す。

2.2 パフォーマンス原則（SE予算）

  • requestAnimationFrame 内で都度 new／配列生成をしない（GC＝ゴミ集めによるカクつき防止）
  • 異変差分は「差し替えスプライト」中心。重いフィルタはクリア演出のみ
  • 音は短いSEをプリロード。BGMはループ1本＋異変時のレイヤ重ね
  • リサイズはデバウンス（連続イベントの間引き）

3. コアループ／数値設計

3.1 1部屋フロー

入室 → 観察(2〜5秒) → 判定 ├ 正常だと思う → 正面ドアへ前進 └ 異変だと思う → 引き返し / 異変をタップ捕食 ↓ 判定結果 ├ 正解 → 成長演出(0.6〜0.9s) → 次部屋 └ 不正解 → ぷしゅ〜縮み → 0.8s以内にLv1へ再開

3.2 ステージ構成

項目値意図
部屋数7約1分、失敗時の苛立ちを抑制
正常部屋比率55〜60%テンポ維持（探し疲れ防止）
異変部屋比率40〜45%緊張の維持
連続正常の上限2油断のあとに罠が続くのを防止
1部屋異変数原則1認知負荷の制御
基準部屋開始時3秒提示「正常」の学習

3.3 操作（タッチ）

操作入力備考
前進中央〜上部タップ／上スワイプ誤操作しにくい広いヒット
引き返し下スワイプ or 左下ボタン常時表示は小さめ
捕食異変オブジェクト直タップ判定を少し広め
ヒント長押しで正常チラ見せ1ステージ1〜2回まで

3.4 異変タイプと正解アクション

タイプ正しい対処微ヒント失敗しやすい誤操作
逃げ系（危険）引き返す冷たい青光食べようとする
捕食系（エキス）タップ捕食甘いピンク光引き返してしまう
序盤チュートリアルで色ヒントを学習させ、中盤以降はヒント強度を下げる。 「異変＝全部食べていい」にすると判断が消え、ゲームが薄くなる。

4. 育成・失敗・エリア

4.1 成長2レーン

レーン条件変化
通常成長正常部屋を正解突破サイズ＋1、光沢・色の濃さ
変異成長捕食系を正解捕食パーツ追加（ツノ・羽など）

4.2 Lv段階（7部屋）

Lv見た目
1手のひらサイズ、目だけ
2–3ぷにっと弾む、ハイライト増
4–5エリア色へ寄り、軌跡出現
6–7表情リッチ、脱出ドヤ顔

4.3 失敗

  • 異変無視で前進 → トラップ → 「ぷしゅ〜」で Lv1 へ
  • 結果で異変を短くチラ見せ（学習可能に）
  • 同じシード近傍で再開可能にし、「さっきの部屋」を覚えられるようにする
  • 連続失敗2回でスライムが微ヒント（震え／目線）

4.4 エリアロードマップ（完成後拡張）

エリアv1異変の味進化系統
ダンジョン必須青炎・壁画・二重影冒険（ツノ／盾）
お菓子の城完成後溶ける床・逆さまキャンディ天使／ダーク分岐
宇宙船完成後重力・偽警報スーツ／ビーム核

5. 画面構成・演出・音

5.1 画面一覧

画面要素SE注記
タイトルロゴ、スライムアイドル、はじめる縦1画面に収める
プレイ部屋背景、装飾、ドア、スライム、操作HUDは最小、ゴールを隠さない
成長演出スケール、パーツ装着、SE0.9秒以内
失敗縮み、異変チラ見せ、即再開長いゲームオーバー禁止
クリア脱出、図鑑スタンプ、もう一回短く祝福
図鑑異変／変異リストポーズから

5.2 ビジュアル方向

  • パステル基調＋アクセントのピンク／ラベンダー
  • 線は太め・角丸。影は柔らかく（多重ドロップシャドウ禁止）
  • スライムはベクトル風スプライト（拡大しても綺麗）
  • 異変差分は「差し替えパーツ」で明確に（プレイヤーが言語化できる差）

5.3 サウンド

種類方針
BGMやさしいループ。異変部屋で低音レイヤを薄く足す
成長SE「ぷにっ」系。毎回聞きたくなる短さ
失敗SE「ぷしゅ〜」。不快音は使わない
音異変v1後半。サイレント時はバイブで代替ヒント

6. 縦スライス定義と制作順序

6.1 成果物ロードマップ（依頼どおり1つずつ）

#成果物完了条件
①企画書PDF（本ドキュメント）技術・ループ・完成定義が合意できる
②異変リストダンジョン12＋拡張候補をカード化
③遊べる縦スライスPages上で7部屋を通しプレイ可能

6.2 縦スライス（③）の受け入れ基準

  • タイトル → 7部屋 → クリア／失敗再開が通る
  • 正常／異変が混在し、前進・引き返し・捕食が機能
  • 正解でスライムがLvアップして見た目が変わる
  • iPhone SE相当幅でレイアウトが崩れない
  • file:// ではなく HTTPS（Pages）またはローカルHTTPで動作

6.3 実装順序（③に向けて）

  1. Vite + PixiJS スケルトン、FSM、リサイズ
  2. 正常部屋テンプレ＋ドア遷移
  3. 異変差し替え3種で判定ロジック
  4. 成長演出と失敗リスタート
  5. 異変を12種まで拡張、図鑑の最低限
  6. SE／微パーティクルで艶出し

7. リスクと検証指標

リスク兆候対策
異変が難しすぎる連続失敗で離脱ヒント段階、チラ見せ、判定拡大
異変が簡単すぎる観察ゼロでクリア小異変比率を上げる
成長が弱い正解が嬉しくないスケール＋パーツ＋SEを強化
テンポ崩壊演出が長い演出上限0.9秒を死守
SEで重いフレーム落ちモバイル軽量モード

7.1 自分テストの指標（広告なし）

指標目標
1セッションの再プレイ平均3回以上「もう一回」したくなる
初見クリア率20〜40%（簡単すぎ／難しすぎの中間）
1部屋平均時間4〜8秒
失敗後の即再開率70%以上が3秒以内に再開
次の成果物②: 異変リスト（ダンジョン12種を「差分／逃げor捕食／難易度／トーン」付きでカード化。お菓子・宇宙の拡張候補も併記）。
