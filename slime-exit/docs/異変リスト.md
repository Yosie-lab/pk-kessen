## 凡例

| 列 | 意味 |
|----|------|
| ID | 管理番号 |
| タイプ | **逃げ**＝引き返し正解 / **捕食**＝タップ捕食正解 |
| 難易度 | L1＝一発で分かる / L2＝端・影など小差分 / L3＝音・時間差 |
| トーン | かわいい / クスッ / ほの怖 |
| 縦スライス | ③に入れる優先度（★必須 / ○あると良い / －後回し） |

**用語:**  
- **差分**＝正常部屋と比べて変わっている点  
- **逃げ系**＝危険・呪い。食べると失敗しやすい  
- **捕食系**＝エキスになる違和感。飲むと変異成長

## D. 実装メモ（縦スライス向け）

### データ1件の形（案）

```json
{
  "id": "D02",
  "name": "ニヤける壁画",
  "type": "eat",
  "difficulty": 1,
  "tone": "gag",
  "hotspot": { "x": 0.62, "y": 0.28, "r": 0.08 },
  "swap": "mural_smile",
  "hintTint": "pink",
  "mutation": "horn"
}
```

| type | 意味 |
|------|------|
| `flee` | 引き返し正解 |
| `eat` | ホットスポット捕食正解 |
| `none` | 正常部屋 |

### バランス指針

| ルール | 値 |
|--------|-----|
| 1部屋の異変 | 原則1つ |
| L3（音） | v1は最大1部屋。サイレント救済必須 |
| 連続正常 | 最大2 |
| 捕食ご褒美 | 序盤に1回は確実に入れる（D02/D06/D08） |
