# AI デイリーニュースブリーフィング

過去24時間以内の AI 関連ニュースから、**仕事・ビジネスへの影響が大きいもの**を重要度順にピックアップし、わかりやすい日本語でまとめる。

## 実行タイミング

- **定例**: 毎朝 6:00（JST を想定。Automations のタイムゾーン設定に合わせる）
- **手動**: Agent チャットで `/ai-daily-news-briefing` を実行
- **Automation 設定**: `.cursor/automations/ai-daily-news-briefing/AUTOMATION.md` を参照
  - Cloud: [cursor.com/automations](https://cursor.com/automations) → cron `0 6 * * *` / TZ `Asia/Tokyo` / リポジトリなし
  - 詳細手順: `references/setup-guide.md`（Automation 側）

## 前提

- 回答は **必ず日本語**
- 結論ファースト。挨拶・前置き・お世辞は不要
- 不確かな情報は推測せず「未確認」「複数ソースで矛盾」と明記
- 対人営業・大規模組織運用より **個人完結型（AI/自動化/直販）** の視点で示唆を書く
- 専門用語には短い解説を付ける

---

## 手順

### 1. 対象期間の確定

- 基準時刻: 実行時刻（通常 06:00 JST）
- 対象: **過去24時間** に公開・更新された情報
- 出力冒頭に `📅 対象期間: YYYY-MM-DD HH:MM 〜 YYYY-MM-DD HH:MM (JST)` を記載

### 2. ニュース収集（WebSearch を複数回使用）

最低 **6〜10 クエリ** を英語・日本語混在で実行し、偏りを防ぐ。1回の検索に頼らない。

**必須カテゴリ**（各カテゴリ最低1クエリ）:

| カテゴリ | 検索例 |
|---------|--------|
| 大手モデル・API | `OpenAI OR Anthropic OR Google Gemini AI news last 24 hours` |
| 規制・政策 | `AI regulation policy news today` / `AI 規制 ニュース 今日` |
| エンタープライズ | `enterprise AI tools launch pricing business` |
| 開発者向け | `AI developer tools SDK framework release` |
| 資金・M&A | `AI startup funding acquisition today` |
| 日本国内 | `生成AI ニュース 今日 ビジネス` |

**優先ソース**（信頼度順）:

1. 公式ブログ・プレスリリース（OpenAI, Anthropic, Google, Microsoft, Meta 等）
2. 主要テックメディア（TechCrunch, The Verge, Ars Technica, Reuters, Bloomberg）
3. 日本語: ITmedia, Impress Watch, 日経クロステック, PR TIMES（AI関連）
4. arXiv / Hugging Face（重大なモデル公開時のみ）

**除外**:

- リーク・未確認噂のみの記事
- 24時間より古い情報（例外: 24時間以内に新事実が判明した継続報道）
- エンタメ・ゴシップ・個人 SNS 投稿のみの根拠

### 3. ビジネス影響度でスコアリング

各候補に **1〜5点** を付け、合計でランク付け。

| 観点 | 配点 | 基準 |
|------|------|------|
| 収益・コストへの影響 | 0〜2 | API 値上げ/値下げ、新プラン、代替手段の出現 |
| 仕事のやり方の変化 | 0〜2 | 開発・制作・運用フローが変わるか |
| 競争優位の変化 | 0〜1 | 個人/小規模が大手に追いつける/置いていかれるか |
| 規制・リスク | 0〜1 | 利用制限、著作権、データ保護 |
| 実用性（今すぐ使えるか） | 0〜1 | GA（一般提供）済みか、ベータのみか |

- **5点以上**: 🔴 最重要（必ず本文に含める）
- **3〜4点**: 🟡 重要（含める）
- **1〜2点**: ⚪ ウォッチリスト（見出しのみ）
- **0点**: 除外

### 4. 出力フォーマット

`references/output-template.md` の構造に従う。以下を必須とする:

1. **3行エグゼクティブサマリー** — 今日いちばん知っておくべきこと
2. **重要ニュース TOP 3〜7** — スコア降順
3. **各項目**: 見出し / 概要 / ビジネスへの影響 / 個人向けアクション / ソース URL
4. **ウォッチリスト** — 重要度低めだが追跡価値あり
5. **今日の1アクション** — 5分以内でできる具体行動1つ

### 5. 品質チェック（出力前）

- [ ] すべて過去24時間以内の情報か
- [ ] ソース URL が付いているか
- [ ] 同じニュースの重複がないか
- [ ] 日本語で非エンジニアにも読めるか
- [ ] 「で、自分は何をすればいい？」に答えているか

## 文体ルール

- 見出しは具体的（「OpenAI が〜」ではなく「OpenAI、API 料金を20%値下げ — 小規模開発者の固定費が下がる」）
- 1項目 150〜250 字を目安（長い場合は箇条書き）
- 数値・日付・バージョン名は可能な限り明記
- リンクは Markdown 形式 `[媒体名](URL)`

## エラー時

- 検索結果が少ない: 対象期間を明示し、取得できた範囲で要約。無理に埋めない
- ソース矛盾: 両方の見解を並記し、確定情報を区別
- ネットワーク不可: 実行不可を報告し、手動 `/ai-daily-news-briefing` 再実行を案内
