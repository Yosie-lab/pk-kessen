# AI デイリーニュースブリーフィング

過去24時間以内の AI 関連ニュースから、**仕事・ビジネス・株価への影響が大きいもの**を重要度順にピックアップし、わかりやすい日本語でまとめる。

## トリガー（これで実行）

次のいずれかを言われたら、このスキルを実行する:

| 言い方 | 備考 |
|--------|------|
| **今日のニュース** | 最優先トリガー。チャットで要約を出し、ファイルも更新 |
| 今日のAIニュース / デイリーブリーフィング | 同上 |
| `/ai-daily-news-briefing` | スラッシュコマンド |
| 毎朝 6:00 Automation | ローカル IDE Automation |

## 実行タイミング

- **定例**: 毎朝 6:00（JST。Automations のタイムゾーン設定に合わせる）
- **手動**: Agent チャットで「今日のニュース」または `/ai-daily-news-briefing`
- **Automation 設定（従量課金なし）**: Mac → Customize → Automations → Daily 06:00
  - 詳細: `.cursor/automations/ai-daily-news-briefing/references/setup-guide.md`
  - ⚠️ **cursor.com/automations（Cloud）は使わない** — Cloud Agent 従量課金が発生

## 前提

- 回答は **必ず日本語**
- 結論ファースト。挨拶・前置き・お世辞は不要
- 不確かな情報は推測せず「未確認」「複数ソースで矛盾」と明記
- 対人営業・大規模組織運用より **個人完結型（AI/自動化/直販）** の視点で示唆を書く
- 専門用語には短い解説を付ける（用語のあとに括弧で一言）
- 投資助言はしない。株価言及は「市場の反応・観測」として事実ベースで書く

### 外部アクセス権限（読み取り専用）

| 操作 | 可否 |
|------|------|
| WebSearch / 公式ページの取得 | ✅ 可（読み取り） |
| `news/今日のニュース.md` と `news/archive/` のローカル更新 | ✅ 可 |
| git push / PR 作成・更新 | ❌ 禁止（ユーザーが明示したときのみ） |
| Slack / X / メールなど外部投稿 | ❌ 禁止 |
| ゲーム本体・無関係ファイルの変更 | ❌ 禁止 |

ネットワーク越しにできることは **情報の取得だけ**。外への送信・公開はしない。

## 手順

### 1. 対象期間の確定

- 基準時刻: 実行時刻（通常 06:00 JST）
- 対象: **過去24時間** に公開・更新された情報
- 出力冒頭に `📅 対象期間: YYYY-MM-DD HH:MM 〜 YYYY-MM-DD HH:MM (JST)` を記載

### 2. ニュース収集（WebSearch を複数回使用）

最低 **6〜10 クエリ** を英語・日本語混在で実行し、偏りを防ぐ。1回の検索に頼らない。

**必須カテゴリ**（各カテゴリ最低1クエリ）:

| カテゴリ | 検索例 |
|---------|--------|
| 大手モデル・API | `OpenAI OR Anthropic OR Google Gemini AI news last 24 hours` |
| 規制・政策 | `AI regulation policy news today` / `AI 規制 ニュース 今日` |
| エンタープライズ | `enterprise AI tools launch pricing business` |
| 開発者向け | `AI developer tools SDK framework release` |
| 資金・M&A・株価 | `AI startup funding acquisition stock market impact today` / `生成AI 株価 今日` |
| 日本国内 | `生成AI ニュース 今日 ビジネス` |
| X/SNS トレンド（補助） | `AI news Twitter OR X discussion today` ※一次情報は公式・報道で裏取り必須 |

**優先ソース**（信頼度順）:

1. 公式ブログ・プレスリリース（OpenAI, Anthropic, Google, Microsoft, Meta 等）
2. 主要テック/金融メディア（TechCrunch, The Verge, Reuters, Bloomberg, CNBC）
3. 日本語: ITmedia, Impress Watch, 日経クロステック, 株式新聞, PR TIMES（AI関連）
4. X（旧Twitter）: 公式アカウントの一次発表のみ採用。個人投稿・噂は除外（または「未確認」と明記）

**除外**:

- リーク・未確認噂のみの記事
- 24時間より古い情報（例外: 24時間以内に新事実が判明した継続報道）
- エンタメ・ゴシップ・個人 SNS 投稿のみの根拠

### 3. ビジネス・株価影響度でスコアリング

各候補に **1〜5点** を付け、合計でランク付け。

| 観点 | 配点 | 基準 |
|------|------|------|
| 収益・コストへの影響 | 0〜2 | API 値上げ/値下げ、新プラン、代替手段の出現 |
| 仕事のやり方の変化 | 0〜2 | 開発・制作・運用フローが変わるか |
| 株価・市場への影響 | 0〜1 | 関連銘柄の急騰急落、決算サプライズ、規制で市場が動いたか |
| 競争優位の変化 | 0〜1 | 個人/小規模が大手に追いつける/置いていかれるか |
| 規制・リスク | 0〜1 | 利用制限、著作権、データ保護、サイバー責任 |

※ 観点の合計が5を超える場合は **5点にキャップ** してからランク付けする。

- **4〜5点**: 🔴 最重要（必ず本文に含める）
- **3点**: 🟡 重要（含める）
- **1〜2点**: ⚪ ウォッチリスト（見出しのみ）
- **0点**: 除外

### 4. 出力フォーマット

`references/output-template.md` の構造に従う。以下を必須とする:

1. **3行エグゼクティブサマリー** — 今日いちばん知っておくべきこと
2. **重要ニュース TOP 3〜7** — スコア降順
3. **各項目**: 見出し / 概要 / ビジネスへの影響 / 株価・市場への影響 / 個人向けアクション / ソース URL
4. **ウォッチリスト** — 重要度低めだが追跡価値あり
5. **今日の1アクション** — 5分以内でできる具体行動1つ

### 5. 保存（「今日のニュース」で見られるようにする）

チャット出力に加え、必ず次を更新する:

1. `news/今日のニュース.md` — **常に最新1日分**（上書き）
2. `news/archive/YYYY-MM-DD.md` — 日付アーカイブ（同日再実行時は上書き可）

チャット冒頭で「📄 最新版: `news/今日のニュース.md`」と案内する。

コード変更・ゲーム本体への影響は不要。`news/` と必要ならスキル文書のみ触る。

### 6. 品質チェック（出力前）

- [ ] すべて過去24時間以内の情報か
- [ ] ソース URL が付いているか
- [ ] 同じニュースの重複がないか
- [ ] 日本語で非エンジニアにも読めるか
- [ ] 「で、自分は何をすればいい？」に答えているか
- [ ] `news/今日のニュース.md` を更新したか

## 文体ルール

- 見出しは具体的（「OpenAI が〜」ではなく「OpenAI、API 料金を20%値下げ — 小規模開発者の固定費が下がる」）
- 1項目 150〜250 字を目安（長い場合は箇条書き）
- 数値・日付・バージョン名・ティッカー（銘柄コード）は可能な限り明記
- リンクは Markdown 形式 `[媒体名](URL)`

## エラー時

- 検索結果が少ない: 対象期間を明示し、取得できた範囲で要約。無理に埋めない
- ソース矛盾: 両方の見解を並記し、確定情報を区別
- ネットワーク不可: 実行不可を報告し、手動で「今日のニュース」再実行を案内
